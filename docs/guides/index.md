# Guides

Task-oriented playbooks for using and extending portable-python.

* [Build a portable python](/guides/build-a-portable-python.md) - Install the tool, build a binary, and use it.
* [Add an external module](/guides/add-an-external-module.md) - Add a new C library to the static-link set.
* [Local development](/guides/local-development.md) - Dev venv, tests, dryrun, and building Linux binaries via Docker.

See also the root [DEVELOP.md](https://github.com/codrsquad/portable-python/blob/main/DEVELOP.md) for the original notes these guides are based on.
